# 申论批改台

一个可以反复练的申论训练工具：读给定材料 → 写答案 → 立刻拿到批改单、改进建议和参考答案，卡住时先看「答题框架」。

打开方式：**https://951367983.github.io/shenlun-practice/**

## 里面有什么

- **23 套仿真材料、100 道题，五类题型各 20 道**：
  - 概括归纳 20 题（问题、做法、成效、原因）
  - 综合分析 20 题（理解一句话、分析原因、评现象）
  - 对策建议 20 题（提对策、建议、措施）
  - 应用文 20 题（短评、倡议书、简报、讲话稿）
  - 大作文 20 题（议论文，700—1200 字）
- **答题框架页**：五类题各一套固定动作——怎么审题、从材料里找什么、按什么维度拆、每一句怎么起头、字数与段落怎么分配、交卷前自检什么，并附一句材料的拆解示范。
- **作答页「拆解思路」**：每题都能就地展开三步提示（分几条、按什么维度、用什么句式），不用跳页；点一下直达该题型的完整框架。
- **题架按题型筛选**：全部 / 概括 / 分析 / 对策 / 应用文 / 作文，六类标签显示各自题量。
- **弱项诊断**：批改记录页按题型统计平均得分率，标出最弱的一类，一键跳到对应框架。
- **规则批改**：按每题的评分要点比对关键词，再检查结构（总括句、分条、分论点、结尾、文种格式）、语言（字数、口语、书面表达）、论证（事例、分析、数据引语）。
- **要点对照表**：哪条答到了、哪条漏了，命中词是什么，各占几分。
- **照抄检测**：与材料原文重合 22 字以上的句子会被标红。
- **参考答案**：先给结构提纲，再给参考成文和评分标准，最后附本题适用的写作方法。
- **批改记录**：本地保存，含得分率趋势、最高分、逐次明细；可导出 JSON，也可导入旧版记录（合并去重，不覆盖现有数据）。
- **方法库**：内置 207 条写作框架（WX01–WX209），可搜索、按类别筛选，点开看一句话用法。

## 怎么用才有效

1. 先看「答题框架」和题目的「拆解思路」，把作答拆成几条、每条的维度定下来，再动笔。
2. 限时作答（右上角有计时），先不看参考答案。
3. 提交后只看「要点对照」和「改进建议」，自己改一遍。
4. 改完再展开参考答案，比较结构而不是比句子。
5. 隔 3—7 天重写同一题，看要点覆盖数和得分率有没有上升；记录页的弱项诊断会告诉你该补哪一类。

## 说明

- 材料为**仿真命题**，依据公开政策方向与常见治理议题编写，不是真题原文，也不代表官方答案。
- 批改是规则引擎，不是人工阅卷：分数用于判断“要点漏没漏、结构顺不顺”，不能等同于真实考试成绩。
- 所有作答与记录只存在本机浏览器（localStorage），不上传、不联网；换设备或清缓存前请先导出 JSON。
- 方法库整理自抖音博主「加夜班的文兄」的 209 条写作框架（开源项目 super-official-writer 蒸馏），仅供个人学习，不作商业再分发。
