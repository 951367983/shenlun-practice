# 申论批改台

一个可以反复练的申论训练工具：读给定材料 → 写答案 → 立刻拿到批改单、改进建议和参考答案。

打开方式：**https://951367983.github.io/shenlun-practice/**

## 里面有什么

- **5 套仿真材料、9 道题**，覆盖申论常考的五种动作：
  - 概括归纳（城市更新问题、脐橙产业做法）
  - 综合分析（“小马拉大车”理解、“三不”原因）
  - 对策建议（基层减负、数字化转型）
  - 短评写作（“小窗口”撬动“大服务”，500 字）
  - 大作文（“留”与“改”、“土特产里的大文章”，1000—1200 字）
- **规则批改**：按每题的评分要点比对关键词，再检查结构（总括句、分条、分论点、结尾）、语言（字数、口语、书面表达）、论证（事例、分析、数据引语）。
- **要点对照表**：哪条答到了、哪条漏了，命中词是什么，各占几分。
- **照抄检测**：与材料原文重合 22 字以上的句子会被标红。
- **参考答案**：先给结构提纲，再给参考成文和评分标准，最后附本题适用的写作方法。
- **批改记录**：本地保存，含得分率趋势、最高分、逐次明细，可导出 JSON。
- **方法库**：内置 207 条写作框架（WX01–WX209），可搜索、按类别筛选，点开看一句话用法。

## 怎么用才有效

1. 先不看参考答案，限时作答（右上角有计时）。
2. 提交后只看“要点对照”和“改进建议”，自己改一遍。
3. 改完再展开参考答案，比较结构而不是比句子。
4. 隔 3—7 天重写同一题，看要点覆盖数有没有上升。

## 说明

- 材料为**仿真命题**，依据公开政策方向与常见治理议题编写，不是真题原文，也不代表官方答案。
- 批改是规则引擎，不是人工阅卷：分数用于判断“要点漏没漏、结构顺不顺”，不能等同于真实考试成绩。
- 所有作答与记录只存在本机浏览器（localStorage），不上传、不联网。
- 方法库整理自抖音博主「加夜班的文兄」的 209 条写作框架（开源项目 super-official-writer 蒸馏），仅供个人学习，不作商业再分发。
